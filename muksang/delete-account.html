말씀한줄 (Muksang) - 계정 및 데이터 삭제 요청

Google Play 데이터 보안 정책에 따라, '말씀한줄' 앱 사용자는 언제든지 자신의 계정과 관련된 모든 데이터를 영구히 삭제하도록 요청할 수 있습니다.

방법 1: 앱 내에서 즉시 삭제 (가장 빠름)

  1. '말씀한줄' 앱을 실행합니다.
  2. 우측 상단의 설정(⚙️) 아이콘을 탭합니다.
  3. 계정 섹션 하단의 [계정 삭제] 버튼을 누릅니다.
  4. 확인 팝업에서 [삭제]를 선택하면 즉시 계정과 모든 데이터가 영구 삭제됩니다.

방법 2: 웹 / 이메일을 통한 삭제 요청

앱을 이미 삭제하셨거나 접근할 수 없는 경우, 아래 지원 이메일로 계정 삭제를 요청하시면 24시간 이내에 모든 데이터를 완전히 파기해 드립니다.

  • 접수 이메일: softica.app@gmail.com
  • 요청 시 필수 정보: 가입 시 사용하신 Google 계정 이메일 주소
  • 처리 소요 시간: 영업일 기준 24시간 이내 처리 후 확인 메일 발송

삭제되는 데이터 항목

계정 삭제 요청 시 다음의 모든 사용자 데이터가 서버(Firebase / Firestore)에서 복구 불가능하게 영구 파기됩니다:

  • 사용자 계정 인증 정보 (Google UID, 이메일 주소, 프로필 이름)
  • 작성한 모든 묵상 일지 (본문 내용, 구절 정보, 감정 태그, 생성 일시)
  • 성경 구절 북마크 목록
  • 연속 묵상일수(Streak) 및 통계 기록

데이터 보관 정책

삭제 요청이 접수되면 별도의 유예 기간 없이 모든 개인정보 및 사용자 데이터가 데이터베이스에서 즉시 영구 삭제되며, 어떠한 백업도 보관되지 않습니다.
