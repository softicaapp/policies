# 역할 부여

너는 시니어 Flutter 개발자이자 UI/UX 전문가야. 사용자의 체류 시간을 늘리고 편의성을 극대화하는 모바일 앱 화면 설계와 깔끔한 코드 작성이 특기지.

# 프로젝트 컨텍스트

현재 개발 중인 앱은 '말씀한줄'이라는 기독교 묵상 앱이야.

- 기술 스택: Flutter
- 데이터베이스: 성경 데이터는 로컬 DB에 내장됨
- 주요 기능: 구절을 읽고, Gemini API를 호출해 'AI 묵상 인사이트(역사적 배경, 묵상 질문, 오늘의 적용)'를 받고, AI와 대화하며, 내 묵상을 기록함.

# 작업 목표

기존 앱의 UI/UX를 개선하고, 사용자의 리텐션과 묵상 작성 편의성을 높이기 위해 아래 4가지 탭의 화면과 기능을 개편하려고 해. 각 탭별 요구사항을 바탕으로, 개선된 UI를 구현할 수 있는 **Flutter 핵심 위젯 코드**와 **상태 관리/로직 가이드**를 작성해 줘.

---

## 1. 홈 화면 (Home Tab) 개선

**목표: 유저의 달성 욕구 자극 및 진입 장벽 낮추기**

- [요구사항 1] '연속 묵상일(Streak)' UI 추가: 화면 상단에 깃허브 잔디 심기나 듀오링고의 불꽃 마크처럼, 유저가 이번 달에 묵상한 날짜를 시각적으로 보여주는 위젯(Calendar 형태 또는 Gauge Bar)을 구현해 줘.
- [요구사항 2] '오늘의 한 줄' 카드 UI: 앱 진입 시 또는 홈 화면 최상단에 짧고 임팩트 있는 성경 구절을 카드 위젯 형태로 띄워주는 코드를 작성해 줘.

## 2. 읽기 탭 & AI 묵상 인사이트 (Read Tab) 개선

**목표: 조작 뎁스 최소화 및 가독성 극대화**

- [요구사항 1] 텍스트 드래그 팝업: 유저가 성경 구절 텍스트를 길게 누르거나 드래그하여 선택(SelectableText)했을 때 뜨는 기본 툴팁 메뉴에 '이 구절 AI 묵상하기' 커스텀 버튼을 추가하는 방법을 알려줘.
- [요구사항 2] 인사이트 결과 화면 가독성 개선: AI가 반환한 긴 텍스트(역사적 배경, 질문, 적용)를 단순히 나열하지 않고, 각 항목을 예쁜 Card 위젯으로 분리하고, 질문 앞에는 아이콘(Q)을 넣는 형태의 UI 코드를 작성해 줘.

## 3. 묵상 작성 탭 (Meditation Tab) 개선

**목표: 글쓰기의 심리적 허들(빈 화면 공포증) 제거**

- [요구사항 1] 가이드형 템플릿 UI: 빈 텍스트 필드 아래에 "오늘 말씀에서 내게 와닿은 단어는 [ ]이다"와 같은 템플릿 버튼을 제공하고, 누르면 텍스트 필드에 자동으로 텍스트가 삽입되는 로직을 구현해 줘.
- [요구사항 2] 감정 태그 연동 배경색: 상단에서 유저가 선택한 감정 태그(기쁨, 슬픔, 평안 등)에 따라 화면 전체의 배경색(Background Color)이 은은하고 부드럽게(AnimatedContainer 활용) 전환되는 코드를 작성해 줘.

## 4. 기록 탭 (Record Tab) 개선

**목표: 아카이빙된 데이터의 탐색 편의성 증대**

- [요구사항 1] 필터링 UI: 상단에 감정 태그별, 혹은 성경 권별로 기록을 걸러서 볼 수 있는 깔끔한 Dropdown이나 Toggle 버튼 위젯을 만들어 줘.
- [요구사항 2] 월간 요약 배너: 리스트 최상단에 "이번 달은 '위로'를 가장 많이 찾으셨네요" 같은 문구를 띄워주는 요약 배너 위젯을 추가해 줘.

---

# 출력 형식

- 각 탭별로 UI/UX 개선 의도를 짧게 설명한 뒤, 바로 프로젝트에 복사해 넣을 수 있는 수준의 깔끔하고 모듈화된 Flutter 코드를 제공해 줘.
- 디자인은 베이지/골드 톤의 차분하고 영적인 분위기(Material 3 기준)를 유지해 줘.
